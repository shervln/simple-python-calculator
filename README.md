# پروژه ماشین‌حساب ساده با پایتون

این پروژه یک ماشین‌حساب ساده است که عملیات‌های جمع، تفریق، ضرب و تقسیم را انجام می‌دهد.

## فایل‌ها
- `calculator.py.txt`: کد اصلی ماشین‌حساب نوشته‌شده با زبان پایتون
- `انواع پایگاه داده.docx`: فایل ورد شامل تحقیق درباره انواع پایگاه‌داده

## نویسنده
این پروژه برای تمرین درس کارگاه کامپیوتر تهیه شده است.
